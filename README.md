# Task Manager Project 

Project description 
The task manager program is designed for small businesses. 
The program allows small businesses to manage tasks assigned to each member of the team. 

The program works with two text files, namely, 'tasks.txt' and 'user.txt'.
The 'user.txt' file stores the username and corresponding password for each user with permission to use the program. The username and password are stored in the following format:
username followed a comma, a single space and then the password. 

The 'tasks.txt' file stores a detailed list of all the tasks of the small business. 
The following data is stored for each of tasks: 
- The username of the person assigned the task. 
- The title of the task.
- A description of the task.
- The date the task was assigned. 
- The due date for the task. 
- A 'Yes' or 'No' specifying if the task has been completed.
